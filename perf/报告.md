# 优化报告：KVideo 首页打开到能用

日期：2026-09-29。口径：Fast 4G（20ms RTT / 4Mbps），冷缓存，10 次取 p75，
配对测量为同场 A/B 交替各 10 次（含 1 轮预热），见 `perf/bench/paired.json`。

## 前后对比

| 操作 | 口径 | 优化前 p75 | 优化后 p75 | 降幅 | 配对测量时段 |
|---|---|---|---|---|---|
| 打开首页到搜索框可输入 | Fast 4G | 580.3ms | 262.6ms | **54.7%** | 2026-09-29 下午 |

| 计数 | 优化前 | 优化后 |
|---|---|---|
| 关键路径请求数 p75 | 19 | 12 |
| 关键路径传输字节 p75 | 210,404 B | 61,706 B |
| SSR HTML 中的搜索框 | 无 | 有 |
| 完整加载 icon 图片字节 | 1,225,972 B | 约 9,000 B |

## 每一步的贡献

1. 拆分图标（-1.2MB 完整加载字节）：对 ready 无直接影响，慢网省带宽。
2. 首页拆服务端组件 + 客户端岛：为第 4 步铺路，单独无收益。
3. Suspense 包裹 ssr:false 组件：防御性修复，单独无收益。
4. PasswordGate 无密码站点放行 SSR：**主贡献**，SSR 从空壳变为完整首屏，
   ready 638ms → 287ms（串行测量），配对终测 -54.7%。

## 护栏

- 功能冒烟：`node perf/bench/smoke.mjs http://127.0.0.1:3000/` 全绿
  （标题、搜索框可见、品牌可见、搜索更新 URL、无控制台报错）。
- 视觉回归：`node perf/bench/visual-diff.mjs` 桌面 1280×800 / 移动 390×844，
  前后像素差 0.01%（阈值内）。
- 权限护栏：配置 `ADMIN_PASSWORD` 启动时，SSR HTML 不含内容（curl 验证），
  客户端水合后显示锁屏、不显示搜索框。
- 棘轮：`perf/bench/ceilings.json` 记录优化后 p75 上限；
  `node perf/bench/ratchet.mjs check --result <new.json>` 超过上限（时间 5% 容差、
  计数 0 容差）退出码 1，已用合成回归数据验证会拦下。
- SEO：title / meta description 前后一致（curl 对比）。

## 风险与回滚

- 行为变化：无密码站点首屏改为服务端渲染；有密码站点行为不变。
  密码判定复用 layout 传入的 `hasAuth`（与 `/api/auth` 同一组环境变量），
  SSR 放行仅在 `hasAuth === false` 时发生。
- 回滚：`git revert` 对应提交；每次改动独立，可单独回滚。
- 上线：尚未部署，等待用户批准。
